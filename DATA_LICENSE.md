# YORIMICHI destination data

`catalog.json` is an adapted database distributed under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). The file is the machine-readable copy of the database offered for redistribution. The license applies to the database, separate from app code and personal walking records. The `sources` and `source_licenses` fields preserve attribution and the originating source licenses for each record.

- © OpenStreetMap contributors. [OpenStreetMap copyright and attribution](https://www.openstreetmap.org/copyright).
- Wikidata structured facts are available under [CC0 1.0](https://www.wikidata.org/wiki/Wikidata:Licensing).
- OpenPOI API supplies selected Overture Maps Places records under [CDLA-Permissive 2.0](https://cdla.dev/permissive-2-0/). The catalog retains their per-record attribution. [OpenPOI API sources and licenses](https://docs.openpoiapi.com/) and [Overture attribution](https://docs.overturemaps.org/attribution/).

YORIMICHI selects and combines records, checks source evidence, and adds scores and station proximity estimates. Estimated proximity uses straight-line distances. Railway memberships come from the published rail sources. [Railway provenance and licensing](https://www.openstreetmap.org/copyright) and [Wikidata licensing](https://www.wikidata.org/wiki/Wikidata:Licensing).
